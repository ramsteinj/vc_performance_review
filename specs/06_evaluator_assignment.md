# 06. 평가자 지정

## 원칙
평가자는 별도 테이블이 아니라 `accounts.User`이다.

Review:
- primary_evaluator: User, 필수
- secondary_evaluator: User, 선택

## 규칙
- 1차 평가자는 필수
- 2차 평가자는 optional
- 평가자도 활성 User여야 한다.
- 필요 시 ADMIN role 또는 조직 정책에 맞는 User만 평가자가 되도록 제한한다.
- 자기 자신을 평가자로 지정할 수 있는지 여부는 회사 정책에 따라 결정하되 MVP에서는 금지하는 것을 권장한다.

## 변경
평가가 시작되기 전에는 변경 가능.
제출 후 평가자 변경은 과거 결과 추적성을 위해 제한한다.

## 중요한 설계
Review 생성 시 평가자 FK를 저장한다.
현재 User의 부서/이름 변경이 과거 Review의 평가자 관계를 자동 변경하는 문제가 발생하지 않도록 한다.
